# FiBER — Fisheries Board Exam Reviewer

FiBER is a Flutter-based mobile application designed to help Fisheries students prepare for the Fisheries Technologist Licensure Examination through interactive learning materials, quizzes, mock examinations, flashcards, and educational games.

## Features

- **Study Modules** — Access learning materials for fisheries-related subjects.
- **Mini Quizzes** — Practice through different question formats.
- **Mock Examinations** — Simulate the board examination experience.
- **Flashcards** — Review important concepts and terminology.
- **Educational Games** — Reinforce learning through interactive activities.
- **Progress Tracking** — Monitor learning activities and performance.
- **Firebase Integration** — Support application features that use Firebase services.

## Technologies Used

- Flutter
- Dart
- Firebase / Cloud Firestore
- Visual Studio Code
- Git and GitHub

## Getting Started

### Prerequisites

Install the following tools before running the application:

- Flutter SDK
- Dart SDK (included with Flutter)
- Android Studio or another supported development environment
- Visual Studio Code

### Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/marcoffeebean/FiBER-v2.git
   ```

2. Navigate to the project directory:

   ```bash
   cd FiBER-v2
   ```

3. Install dependencies:

   ```bash
   flutter pub get
   ```

4. Run the application on an available device or emulator:

   ```bash
   flutter run
   ```

Firebase configuration may be required before running the application, depending on the project's current setup.

## Project Purpose

FiBER aims to provide Fisheries students with an accessible and interactive tool for reviewing essential concepts and practicing examination questions in preparation for the Fisheries Technologist Licensure Examination.
